
# Brew & Bloom ☕🌸

**Live site:** https://queenrosemherdumali.github.io/brew-and-bloom/

## About

Brew & Bloom is a cozy café website that combines freshly brewed coffee, delicious pastries, and beautiful flowers. It showcases the café's menu in a warm, welcoming design for coffee lovers and flower enthusiasts.

## Design System

### Palette (60-30-10)

| Role | Share | Color | Used for |
|---|---|---|---|
| Dominant | 60% | `#FFF8E7` | Page background |
| Secondary | 30% | `#E8DCC8` | Cards, sections, navigation |
| Accent | 10% | `#7A4E2D` | Buttons, links, highlights |

### Visual Style

**Style chosen:** Cozy Minimalism with Botanical Elements

**Why I chose it:** I chose this style because the warm coffee colors, clean layout, and floral decorations create a relaxing and welcoming café atmosphere.

### Contrast Check

Body text color vs. background color: `#2B2118` on `#FFF8E7`

Contrast ratio: approximately **14.7:1** (minimum required: 4.5:1)

Tool used: [WebAIM Contrast Checker](https://webaim.org/resources/contrastchecker/)
